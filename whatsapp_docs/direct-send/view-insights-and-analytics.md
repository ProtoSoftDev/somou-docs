# View insights and analytics


**Note:** The Direct Send API is in beta. Features and behavior described here are subject to change and may be released incrementally. Participation is subject to acceptance of the beta terms.

You can retrieve insights and analytics for templates generated by the Direct Send API, both via the API and within WhatsApp Manager.

## Via the API

The Template Analytics API takes template IDs directly through the `template_ids` parameter, so you don&#039;t need to convert a template ID to a template name. Pass the `template_id` of the generated template. See [Template analytics](https://developers.facebook.com/docs/whatsapp/business-management-api/analytics#template-analytics).

You can find the `template_id` in the message-status webhook — see [Message success and pricing](https://developers.facebook.com/documentation/business-messaging/whatsapp/direct-send/supported-message-types#message-success-and-pricing).

## Via WhatsApp Manager

1. Go to **WhatsApp Manager** &gt; **Manage Templates**.
2. Hover over the generated template, then click **View insights**.

&gt; **Note.** WhatsApp Manager lists templates by name. If you only have a `template_id` (for example, from the message-status webhook), use the [Message Templates API](https://developers.facebook.com/documentation/business-messaging/whatsapp/reference/whatsapp-business-account/message-template-api#get-version-template-id) to resolve it to the template name, then locate that template in the list:

```html
GET /&lt;TEMPLATE_ID&gt;?fields=name
```
